# YutuGs-Photo

**版本：1.1.3-alpha**  
**交付类型：完整源码替换包**

本版本延续 alpha.4 演进代码线，以上一版 `1.1.2-alpha` 为代码基线；0.4.9 工程只作为功能、菜单和交互行为对照，不作为代码基线。每次交付均为完整源码替换包。

## 1.1.3-alpha 本轮功能

- **画笔/橡皮擦**：画笔创建可编辑 SVG 矢量笔迹；橡皮擦通过当前矢量图层的 SVG mask 非破坏式擦除。支持笔刷大小、颜色、历史记录和 YGS 保存。此处不是 Photoshop 像素笔刷/像素橡皮擦引擎。
- **钢笔/节点**：钢笔点击创建角点、按住拖动创建对称 Bézier 控制柄，双击或 Enter 结束路径；节点工具可拖动锚点及入/出控制柄。
- **滴管/油漆桶**：滴管读取矢量对象填充/描边；油漆桶修改命中矢量对象填充。栅格像素取色和洪泛填充未实现。
- **文字属性**：文字内容、字体、字号、字重、样式、颜色均可编辑；桌面端调用 Rust/Tauri 命令枚举系统字体，浏览器预览回退到常用字体列表。
- **路径布尔**：联合、减去、相交、排除生成闭合 YGS 路径对象，支持矩形、椭圆和凸多边形。非凸路径、自交路径和曲线精确布尔尚未实现；曲线以多边形采样近似。
- **滤镜/调整图层**：矢量对象可用 SVG 高斯模糊、亮度、色相旋转；亮度/对比度调整图层可作用于下方图层合成组。
- **多画板**：画板并排显示、画板列表切换、点击其他画板激活、适合全部画板视图。画板各自拥有图层集合，但视口共享，跨画板对象选择/拖动尚未实现。
- **新建文档**：双入口新建窗口：Photoshop 2026 风格像素文档、Illustrator 2025 风格画板文档；支持预设、名称、宽高、单位、PPI、RGB/CMYK/灰度元数据、背景和画板数量。

### 新建文档的颜色与单位说明

- 像素、毫米、厘米、英寸可换算为文档像素；分辨率以 PPI 存储。
- CMYK 目前只是文档色彩模式元数据，浏览器 SVG 预览仍为 RGB。尚未实现完整 CMYK 色彩管理、软打样、分色、专色/专金色输出。
- Illustrator 风格多画板采用同一文档中的独立画板对象和图层集合；目前画板共享缩放/平移视口。

## 核心架构

YGS v2 文档模型 → 对象/图层/画板 → 命令与历史 → 几何/栅格资产 → SVG Renderer。矢量对象、钢笔路径、笔迹、擦除蒙版和滤镜均由 SVG 渲染。禁止 Canvas 2D 编辑、绘制、擦除、像素处理或合成内核；本轮源码扫描以此为验收条件。

PhotoCraft / VectorCraft 不作为运行时依赖。

## 开发

```bash
npm install
npm run typecheck
npm test
npm run build
npm run tauri dev
```

Windows 系统字体枚举由 `src-tauri/src/lib.rs` 中 `list_installed_fonts` 命令实现。AI 本地服务位于 `local-ai-service/`，模型权重不随源码包提供。
